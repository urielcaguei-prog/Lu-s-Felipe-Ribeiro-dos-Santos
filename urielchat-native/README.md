# Uriel Chat — módulo de detecção experimental
O botão flutuante `◎` oculta-se, captura uma única imagem via serviço de Acessibilidade do Android, executa Google ML Kit Pose Detection (modo imagem única), exige confiança mínima para nariz e olhos e, se houver detecção, envia uma tentativa de gesto de correção.

## Limites
Não detecta o disparo nem diferencia inimigos/aliados. O modelo foi desenvolvido para pessoas reais; não foi validado em personagens do Free Fire. Gestos emitidos pelo Android podem ser ignorados pelo jogo. Não garante headshot nem acertos. ESP e Chams não existem nesta compilação. Capturas não são salvas nem enviadas para servidor; inferência local.

## Permissões
Habilitar Acessibilidade e a opção de sobreposição. O aplicativo usa login KeyAuth por licença válida. A senha de administrador não foi incorporada ao código e deve ser renovada no painel KeyAuth por ter sido compartilhada anteriormente.

A versão é experimental; use somente em contextos autorizados. A Garena pode suspender contas pelo uso de software não autorizado.
