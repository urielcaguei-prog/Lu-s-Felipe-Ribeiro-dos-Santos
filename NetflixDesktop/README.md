# Netflix Floating Panel for Windows (Unofficial)
Native Windows Forms desktop application. Compiled as a standalone .exe for Windows 10/11 x64 with embedded .NET runtime.
Features: floating draggable N bubble, always-on-top panel, visual 360° spinning mannequin, head/neck/chest visualization, saved interface settings, emulator executable launcher, process diagnosis, SOCKS5 connectivity handshake. No game modification/injection and no anti-cheat bypass.
Non-affiliated with Netflix, Garena, or Free Fire.
