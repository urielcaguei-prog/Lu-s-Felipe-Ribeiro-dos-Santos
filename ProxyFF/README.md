# Netflix X Proxy FF — Native Android SOCKS5 (unofficial)
This is a repackaged build recipe for the permissive MIT licensed SocksTun Android VPN client and HevSocks5Tunnel engine. Upstream code fetched from github.com/heiher/sockstun at build time, via git submodules. Original MIT license is preserved in upstream clone. Modified by adding a splash/key gate (`luisfreefire`), black/red UI, blue-eyed skull launcher icon and safeguards against false connection status.

## Real capabilities
- VPN via Android VpnService and native HevSocks5Tunnel TCP/UDP SOCKS5 redirection
- Host/IP and port, SOCKS5 credentials, DNS options, global or selected-app routing, status and profiles
- Requires a real reachable SOCKS5 server operated or selected by the user; **the access key is separate from server credentials**
- No modification of Wi-Fi hardware or game RAM; no aimbot, ESP, headshot automation or anti-cheat circumvention
- This branding is not affiliated with Netflix, Garena or Free Fire.

A static client-side access key should not be considered a secure server-side license check. Do not enter Free Fire account credentials into proxy fields.
