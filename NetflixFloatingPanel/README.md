# Netflix Floating Panel V2 — Android
A native, independent user-controlled Android overlay. Uses a black/red original interface with Netflix-style name and N mark as requested. Unofficial: not affiliated with Netflix or Garena.
## Features
- Launcher screen with animated 360° mannequin.
- Draggable floating bubble, expandable scrollable panel, minimized mode, foreground notification.
- Visual target indicator Head / Neck / Chest for illustrative mannequin only.
- Real Android overlay permission and service status detection; Free Fire normal and MAX installed-state checks and launch shortcuts.
- Functional persisted bubble size, transparency, animation speed, rotating display, position, and reset.
- SOCKS5 unauthenticated method negotiation test from the host app (does not route any external traffic).
- No login key for the independent interface.
## Limits
No aimbot, wallhack, ESP against real people, ban bypass, game memory changes, or guaranteed anticheat compatibility are implemented. The skeleton preview is not a game cheat.
Build with Android 35 SDK, JDK 17, Gradle 8.9: gradle :app:assembleDebug.
